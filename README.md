# Rock Paper Scissors

A simple Rock Paper Scissors game built with Python and Tkinter.

## About

This was built on my first day learning Tkinter as a hands-on way to practice Python GUI programming. The game runs in a desktop window where you pick your move and the computer picks randomly.

## Features

- Click-based input with Rock, Paper, and Scissors buttons
- Instant result display showing both your choice and the computer's
- Single reusable click handler for all buttons using event binding
